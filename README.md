# chalcogel-dft-aimd-workflow

DFT and AIMD workflow for structural and electronic characterization of
amorphous Mo_xS_y chalcogel battery electrode materials — including
melt-quench AIMD structure generation, Mo–S bond length and oxidation
state analysis, and XANES edge-position alignment against experiment.

## Contents

- [`xanes_energy_alignment/`](xanes_energy_alignment/) — two-step energy
  alignment of computed core-hole excitation energies (XCH) against
  experimental XANES edge positions, generalized to any edge/compound.
  See that folder's own README for details and usage.
